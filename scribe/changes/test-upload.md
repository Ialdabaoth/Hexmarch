A **Test** button beside "Folder you upload to" (Heph 2026-11-09). It fetches `campaign.json` and `snapshot.json` from the folder, past any cache, and compares each with what the last publish produced: it matches, it isn't there yet (a new upload can take a minute or two to appear), it is an older one, it is a different file, or it can't be read (not JSON, or the host doesn't let other sites read it). Publishing keeps that pair on the device as `published:<id>` for the test; the check itself is `checkUpload` in the shared engine.
