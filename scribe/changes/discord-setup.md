**Discord setup for first-timers** (Heph 2026-11-12). "Where players send requests" offers Discord (preferred), Google Apps Script or Not yet. Under Discord are three steps: make a webhook (Server Settings › Integrations › Webhooks › New Webhook › Copy Webhook URL) and paste it, which Scribe checks; choose who Discord pings when a request arrives (Me, A role, Everyone in the channel or Nobody; how to copy an ID is in a tooltip, and a pasted mention works too); and Send a test post, so the notification can be seen arriving.
