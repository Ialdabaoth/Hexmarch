**GitLab hosting** (Heph 2026-11-17). Hosting › Where to host now offers GitLab, after GitHub. It has the same four beginner steps, each with a link: make an account, create a public project, make a fine-grained key that can only save to that project, and paste it. Before writing, Publish checks the project and key and says in plain words what is wrong. A brand-new empty project works. Players read the files through GitLab's own file addresses, so no GitLab Pages setup is needed. A GitLab you run yourself works too: set its address under Advanced.
