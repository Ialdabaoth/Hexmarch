Traced rivers and frameless battle maps (Heph 2026-11-15, Isle of Mists). A module can trace a river's real course in module.json `atlas.rivers` (`[{name, class?, via: [[lat, lon], ...]}]`): build.py's new `atlas_rivers.py` splices each course into the generated river it lies along, from the point nearest its first end to the point nearest its last (the river with the same name first), or adds it as a river of its own when no river is within 3 miles of its ends. It runs before the roads, so their bridges and fords follow the traced course, and it redraws no map. Roads can be traced the same way: a road in `atlas.roads` with `"traced": true` joins its via points as they are, with no path search and no sway. Battle maps (`encounter_draw.py`) lose their thick black frame, and the Atlas no longer outlines an anchored map on the 100-ft view, so the hexmap runs straight into the map's walls; the Field view still marks where it is.
