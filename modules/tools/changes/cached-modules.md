The module picker offers every module this device knows (Heph 2026-11-10): the site's own, the module repositories the Companion has added, the site of the picked campaign's Scribe record, and map files opened here. With a campaign picked, it shows only the campaign's lockfile modules. The campaign is the `?campaign=` link, else the Launcher's or an app's last pick (`hexmarch-current` in the shared storage, `{campaign: id | null}`; null is "No campaign"), else the Companion's.
