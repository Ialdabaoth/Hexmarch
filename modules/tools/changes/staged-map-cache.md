Map builds redraw only what changed (Heph 2026-11-09). The module build caches three stages separately: the region pass (hexmap.py and the print pages), the Atlas Marches (atlas_convert.py) and the tile cut (atlas_cache.py). Each stage is keyed on its own inputs and code. Python tools count by their syntax tree, so comments, docstrings and layout never redraw, and build.py itself and the module page and manifest step are in no key. Repainting a March reuses the region pass, and the tile cut redoes only that March's Field tile and the League tiles it shares with its neighbours (`atlas_cache.py --state <dir>`). atlas_convert.py is also much faster: painted Marches skip the terrain counts that only generated Marches need, and grouping uses one packed key. Hansa, measured: a full build 19 minutes before, 9.5 now (atlas_convert 10.5 minutes down to 70 seconds, same March PNGs); a rebuild with no map change or only comment edits 2 seconds; one March repainted 1.5 minutes, with the same tiles as a full cut.
