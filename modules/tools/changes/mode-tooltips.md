Movement mode tooltips (Heph 2026-11-16). Every movement mode in the party box, both in a member's line and in the Modes… picker, now has a tap-friendly tooltip: the ruleset's own description of the mode (`movement.modes[].about`), then its talent, speed and limits. Movement itself explains the modes as a whole (`movement.modesAbout`) and how many each member gets, and "helps" explains Help. Without an `about`, the tooltip shows the summary alone.
