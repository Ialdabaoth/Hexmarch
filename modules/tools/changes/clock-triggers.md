Clock triggers (EVENTS_FORMAT.md section 4; E9, Heph 2026-11-15). A trigger `{"on": "clock", "every": {"n": 4, "unit": "hour"}}` fires each time the party's clock crosses that boundary (counted from midnight of its first day), from a module's events or now also from a ruleset's procedures files (`"triggers"`, where a module trigger with the same id wins). During a Navigate walk the Atlas checks each hex's time: an `"auto": true` trigger runs there like the walk's `then` procedures (so E9's lost check each shift can halt the walk), and any other joins the queue with the hex's params and stops the walk there. `"while": "walking"` fires only on a walk, and `"if": {"mode": id}` only while a member is on that mode (Forced March each hour); time passed by a queued run fires the others. An `each` roll for everyone can take `"ease": "<mode>"` so Help on that mode counts (E9: footing on hard ground, where everyone is on Climb/Swim/Maneuver), and the Help picker also offers the modes the ground can force.
